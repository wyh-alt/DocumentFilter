# 文件处理工具

这是一个基于 Python 和 PyQt6 开发的文件处理工具，主要提供文件筛选提取和批量重命名两大功能模块。

## 功能特点

### 批量文件提取

1. **多种匹配方式**：
   - 根据源目录匹配提取：在源目录和目标目录间查找匹配的文件
   - 根据文本匹配提取：通过关键字在目标目录中筛选文件

2. **匹配依据选项**：
   - 完整文件名匹配
   - ID 前缀匹配（支持纯数字、纯英文、英文数字混合的 ID 格式）

3. **文件批量操作**：
   - 复制选中文件到输出目录
   - 移动选中文件到输出目录
   - 删除选中文件
   - 导出匹配结果为 Excel 表格
   - 移动/删除完成后弹窗询问是否重新匹配筛选刷新结果（默认不自动刷新，避免打断操作）

4. **现代化界面**：
   - 双选项卡设计（批量文件提取 / 批量重命名）
   - 表格形式展示匹配结果
   - 支持拖放目录
   - 进度条实时反馈
   - 高亮显示匹配的关键字

### 批量重命名

支持对指定目录下所有文件进行批量重命名，内置以下重命名类型：

| 类型 | 说明 | 示例 |
|------|------|------|
| 添加前缀 | 在文件名前添加自定义文本 | `abc` → `前缀_abc` |
| 添加后缀 | 在文件名后添加自定义文本 | `abc` → `abc_后缀` |
| 删除指定字段 | 删除文件名中的指定文本 | `abc_old` → `abc` |
| 替换指定字段 | 将文件名中的 A 替换为 B | `abc_v1` → `abc_v2` |
| 按升序编号 | 按数字顺序编号 | `abc` → `001_abc` |
| Excel 替换命名 | 通过 Excel 表格批量编辑文件名 | 灵活自定义 |

**重命名安全机制**：
- 预览功能：执行前查看所有新旧文件名对照
- 撤回功能：一键撤销最近一次批量重命名操作
- 冲突检测：自动识别名称冲突（互换/链式），智能选择最优策略
- 两阶段安全重命名：存在名称冲突时先改为临时名再改为目标名，避免文件覆盖

**性能优化（v2.5）**：
- 智能策略选择：无冲突场景使用直接重命名，效率提升约 5-7 倍
- UI 节流更新：减少进度刷新频率，降低 GUI 线程开销
- 对 5000 个文件的重命名操作，耗时从 ~15 秒优化至 ~2 秒

**性能优化（v2.6）**：
- 目录扫描改用 `os.scandir` 单次枚举（替代逐文件属性系统调用），扫描速度提升约 28 倍
- 消除匹配前的重复目录扫描（数量统计与文件加载共用同一份数据），完整匹配流程整体提速约 20 倍
- 结果表格复选框改为轻量控件，大结果集显示速度提升约 2.5 倍
- 实测 2 万源文件对 2 万目标文件的完整匹配流程约 0.16 秒

### Excel 替换命名功能

- 选择重命名目录后，程序自动读取所有文件名并生成 Excel 表格
- 点击"打开表格"使用系统默认程序编辑，只需编辑"重命名"列
- 新名称不含扩展名时自动保持原扩展名
- 程序退出或切换目录时自动清理临时 Excel 文件

## 安装

1. 确保已安装 Python 3.6 或更高版本

2. 克隆仓库：
   ```bash
   git clone <repo-url>
   cd 文件筛选工具
   ```

3. 创建虚拟环境（推荐）：
   ```bash
   python -m venv venv
   venv\Scripts\activate  # Windows
   ```

4. 安装依赖：
   ```bash
   pip install -r requirements.txt
   ```

## 使用方法

### 启动程序

```bash
python file_selector.py
```

### 批量文件提取

1. 选择目标目录和输出目录（支持拖放文件夹）
2. 选择匹配方式：
   - 根据源目录匹配提取：还需选择源目录，设置匹配依据和格式匹配
   - 根据文本匹配提取：输入检索文本（支持多行或分号分隔多个关键字）
3. 点击"查找匹配文件"
4. 在结果表格中勾选需要处理的文件（支持全选/取消全选/反选）
5. 点击复制/移动/删除按钮执行操作（移动/删除完成后弹窗询问是否重新匹配刷新结果）

### 批量重命名

1. 切换到"批量重命名"选项卡，选择重命名目录
2. 选择重命名类型并填写相应参数
3. 点击"预览重命名"查看效果
4. 确认无误后点击"执行重命名"
5. 如需撤销，点击"撤回重命名"

## 匹配方式说明

### 根据源目录匹配提取

| 匹配依据 | 说明 |
|---------|------|
| 完整文件名 | 匹配源目录和目标目录中完全相同的文件名 |
| ID 前缀 | 提取文件名开头的字母数字序列进行匹配（如 `ABC123-文件.txt` 与 `ABC123_其他文件.doc`） |

### 根据文本匹配提取

在目标目录中查找包含指定文本的文件，支持两种模式：

| 模式 | 说明 |
|------|------|
| 完全匹配 | 只匹配文件名（不含扩展名）与输入文本完全相同的文件 |
| 检索匹配 | 匹配文件名中包含输入文本的文件，可选"扩大检索范围"以匹配所有包含该文本的文件 |

## 打包

运行打包脚本生成独立可执行文件：

```bash
python build_exe.py
```

生成的 exe 文件位于 `dist/` 目录下。
